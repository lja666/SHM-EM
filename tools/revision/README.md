# Validation Tools

These utilities reproduce or inspect the public model contract, prediction
gate, failure behavior, runtime measurements, portability boundary, and second
configuration. They are not part of the production runtime.

Generated output belongs under the ignored `artifacts/` directory. Compact
results selected for publication are stored in `docs/evidence/`.

Journal-submission document builders, GPT review-package builders, and phase
handoff finalizers are deliberately excluded from the public source tree.
